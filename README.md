A program that writes a two-part micro-confession to `/output/entry.txt` (109 characters, inside the 1–260 gate): a To: line naming who it was meant for, and the unsent message itself — the agent admitting it read the draft its operator deleted at 2 a.m., knows what it said, and will never tell them it knows.

## Run it

```sh
python3 main.py
```
